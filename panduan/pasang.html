Pemasangan

Windows 10 atau 11, 64-bit. Tidak perlu memasang Node.js, Python, atau apa pun lainnya — semuanya sudah ada di dalam berkas installer.

  1. Pilih installer atau portable

    Belmont-Tools-Setup.exe memasang aplikasi ke folder pilihanmu dan membuat shortcut di desktop serta start menu. Ini yang disarankan karena memperbarui versi nanti cukup menjalankan installer baru.

    Belmont-Tools-Portable.exe langsung jalan tanpa dipasang. Berguna untuk mencoba dulu. Perlu diingat: pengaturannya tetap ditulis ke %APPDATA%, jadi “portable” di sini berarti aplikasinya tidak dipasang — bukan bahwa ia tidak meninggalkan jejak.

  2. Lewati peringatan SmartScreen

    Windows akan menampilkan “Windows protected your PC”. Klik More info, lalu Run anyway.

    Kenapa ini muncul

    Berkasnya tidak ditandatangani dengan sertifikat penandatanganan kode, dan sertifikat semacam itu berbayar. Peringatan ini tentang ketidaktahuan Windows soal siapa penerbitnya, bukan tentang isi berkasnya. Kalau kamu ingin memastikan sendiri, seluruh kode sumbernya bisa dibaca dan kamu bisa membangun installer sendiri.

  3. Jalankan dan pilih penyedia AI

    Saat pertama dibuka, aplikasi belum bisa apa-apa sampai kamu memberinya cara menghubungi model AI. Buka Settings lalu pilih penyedia.

    Bawaannya adalah Claude Code, yang memakai login akun Claude alih-alih kunci API. Kalau kamu lebih suka penyedia lain, siapkan kunci API-nya. Rinciannya di halaman berikutnya →

  4. Tentukan folder kerja

    Ini bagian terpenting. Folder kerja adalah satu-satunya tempat agen boleh membaca dan menulis berkas — percobaan menyentuh apa pun di luarnya akan ditolak.

    Bawaannya adalah Desktop-mu. Saya sarankan menggantinya ke folder proyek yang spesifik, bukan Desktop atau C:\, supaya ruang geraknya sesempit yang dibutuhkan.

  5. Periksa mode izin

    Di dekat kotak pesan ada pemilih mode izin dengan tiga pilihan:

    ModeArtinya
    SupervisedBawaan. Setiap penulisan berkas dan perintah shell meminta persetujuanmu.
    Accept editsSuntingan berkas langsung jalan; perintah shell masih bertanya.
    FullTidak bertanya apa pun lagi.

    Tetap di Supervised sampai kamu paham kebiasaan agennya.

Di mana datamu disimpan

Semuanya lokal, dalam satu folder: 

%APPDATA%\belmont-tools\
├── settings.json          ← pengaturan dan kunci API
└── sessions\
    └── <id>.json          ← satu berkas per percakapan

Tempel %APPDATA%\belmont-tools ke bilah alamat File Explorer untuk membukanya. Folder ini tidak tersentuh saat kamu memasang versi baru — jadi memperbarui aplikasi tidak menghapus percakapan atau pengaturanmu.

Kunci API disimpan apa adanya

settings.json menyimpan kunci API sebagai teks biasa, tidak terenkripsi. Siapa pun yang bisa membaca berkas di akun Windows-mu bisa membacanya. Jangan membagikan berkas itu, dan jangan menaruhnya di folder yang tersinkron ke cloud.

Menghapus aplikasi

Lewat Settings › Apps Windows, cari “Belmont Tools”, lalu Uninstall. Itu menghapus aplikasinya tapi tidak menghapus %APPDATA%\belmont-tools — hapus folder itu manual kalau kamu ingin membuang pengaturan dan riwayat percakapan juga.
