Jalankan dari sumber

Untuk yang ingin memodifikasi aplikasinya atau membangun installer sendiri. Kalau kamu hanya ingin memakainya, installer biasa sudah cukup.

Yang dibutuhkan

  • Node.js beserta npm. Tidak ada versi minimum yang dipatok di proyek; versi LTS yang sedang berlaku aman.
  • Git, untuk mengkloning repo.
  • Windows kalau kamu ingin membangun installer Windows — electron-builder membangun target Windows paling mulus di Windows sendiri.

Tanpa bundler

Tidak ada webpack, Vite, atau TypeScript di sini. Berkas sumber dijalankan apa adanya oleh Electron, jadi menyunting sebuah berkas lalu memulai ulang aplikasi sudah cukup — tidak ada langkah kompilasi.

Menjalankannya

git clone <url-repo>
cd belmont-tools
npm install
npm start

npm install mengunduh Electron, yang ukurannya ratusan megabita — jalankan sekali dan biarkan selesai.

Untuk bekerja sambil melihat DevTools:

npm run dev

Membangun installer

npm run build            # installer NSIS + portable, x64
npm run build:portable   # hanya portable
npm run build:mac        # dmg arm64 (belum diuji / belum dirilis)

Hasilnya muncul di dist/: 

dist\
├── Belmont Tools Setup <versi>.exe
├── Belmont Tools <versi> portable.exe
└── win-unpacked\                      ← cache antar-build

Sebelum setiap build, npm run bersihkan berjalan otomatis untuk menghapus artefak build lama dari dist/. Ini bukan sekadar menghemat ruang — sisa berkas dari build yang gagal pernah membuat NSIS menolak menulis keluarannya. Folder win-unpacked/ sengaja tidak dihapus karena dipakai sebagai cache.

Tiap versi memakan ~300 MB

Installer dan portable masing-masing sekitar 149 MB karena membawa seluruh runtime Electron. Tanpa pembersihan otomatis itu, dist/ menumpuk dengan cepat.

Isi proyeknya

LokasiIsi
src/main/Proses utama Electron: loop agen, tool, penyedia, sesi, jembatan Telegram, MCP
src/main/providers/Satu berkas per penyedia, plus pabrik bersama untuk yang OpenAI-compatible
src/renderer/Antarmuka: HTML, CSS, JavaScript biasa — tanpa framework
scripts/Skrip bantu build

Tool agen dijalankan di proses utama, bukan di renderer, dan setiap path yang disentuh melewati satu fungsi pengaman yang menolak apa pun di luar folder kerja. Kalau kamu menambahkan tool baru, lewatkan path-nya ke fungsi itu juga.

Menandatangani installer

Build bawaan tidak ditandatangani, karena itulah SmartScreen memperingatkan pengguna. Kalau kamu punya sertifikat penandatanganan kode, electron-builder bisa memakainya — lihat dokumentasi electron-builder tentang code signing. Tanpa sertifikat, tidak ada cara menghilangkan peringatan itu.
