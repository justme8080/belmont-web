Penyedia & kunci API

Belmont Tools tidak punya model sendiri dan tidak menjual kuota. Ia menyambung ke penyedia yang kamu pilih, dengan akun atau kunci milikmu sendiri.

Dua jenis penyambungan

Pilihannya terbagi dua, dan perbedaannya penting karena menentukan fitur apa yang kamu dapat.

Claude Code

Memakai login akun Claude, bukan kunci API. Agennya mengendalikan dirinya sendiri dengan tool bawaan Claude Code, dan ini satu-satunya pilihan yang mendukung subagen paralel serta pengatur tingkat usaha.

Penyedia API

Anthropic, OpenAI, Gemini, DeepSeek, Kimi, GLM, ONToken, atau endpoint custom. Perlu kunci API. Agennya memakai tool milik Belmont Tools dan punya peringkasan otomatis saat konteks menipis.

Login akun Claude

  1. Pilih Claude Code sebagai penyedia

    Buka Settings, lalu pilih Claude Code di daftar penyedia. Ini sudah jadi bawaan.

  2. Buka panel Akun Claude

    Di bawah pemilih penyedia ada panel Akun Claude. Mulai proses login dari situ.

  3. Tempel kode OAuth

    Peramban akan terbuka untuk kamu masuk ke akun Claude. Setelah selesai, kamu mendapat kode — tempel kembali ke panel itu.

Variabel environment Anthropic diabaikan dengan sengaja

Kalau komputermu punya ANTHROPIC_API_KEY, ANTHROPIC_BASE_URL, ANTHROPIC_MODEL, atau saudara-saudaranya, Belmont Tools membuangnya dari lingkungan proses Claude Code. Tujuannya supaya sesi di aplikasi ini selalu memakai akun dan model yang kamu pilih di Settings, bukan diam-diam dibelokkan oleh variabel sistem. Kalau kamu memang ingin memakai kunci API Anthropic, pilih penyedia Claude (Anthropic) dan isi kuncinya di Settings.

Mengisi kunci API

  1. Pilih penyedianya lebih dulu

    Kolom kunci API hanya menampilkan satu kunci: milik penyedia yang sedang terpilih. Kunci penyedia lain tetap tersimpan, tidak hilang saat kamu berpindah.

  2. Tempel kunci dari dasbor penyedia

    Ambil dari halaman API key penyedia bersangkutan:

    PenyediaAlamat layanan
    Claude (Anthropic)console.anthropic.com
    OpenAIplatform.openai.com
    Geminiaistudio.google.com
    DeepSeekplatform.deepseek.com
    Kimi (Moonshot)platform.moonshot.ai
    GLM (Zhipu / Z.ai)z.ai
    ONToken.idontoken.id

  3. Tekan Muat ulang di kolom model

    Aplikasi membawa daftar model bawaan sebagai cadangan, tapi daftar itu cepat basi. Tombol Muat ulang menarik daftar sesungguhnya dari penyedia, jadi model yang baru dirilis langsung muncul tanpa menunggu pembaruan aplikasi.

    Kalau tombol itu gagal, biasanya kuncinya salah atau salah tempat — ini cara tercepat memastikan kuncimu benar-benar bekerja.

Endpoint custom

Layanan apa pun yang meniru format OpenAI bisa dipakai — OpenRouter, Groq, Together, vLLM atau Ollama yang kamu jalankan sendiri. Tambahkan dari form endpoint custom di Settings dengan dua hal: base URL dan nama.

Kuncinya opsional, karena server lokal biasanya tidak memerlukannya. Base URL yang dimaksud adalah bagian sebelum /chat/completions — misalnya http://localhost:11434/v1.

Mana yang sebaiknya dipakai

Untuk pekerjaan ngoding sungguhan, Claude Code yang paling kuat di aplikasi ini: subagen paralel membuatnya bisa menelusuri banyak hal sekaligus, dan tool bawaannya lebih matang.

Penyedia API lebih cocok kalau kamu sudah punya kuota di sana, butuh model tertentu, atau ingin biaya yang lebih bisa diprediksi. Untuk percakapan panjang dengan penyedia API, lihat ambang peringkasan otomatis — inilah yang mencegah percakapan mati saat konteks penuh.

Tagihan tetap tanggung jawabmu

Agen bisa memanggil model berkali-kali dalam satu giliran, dan subagen mengalikannya lagi. Pantau penggunaan di dasbor penyedia pada minggu-minggu pertama sampai kamu punya gambaran biayanya.
