Pengaturan

Semuanya tersimpan di %APPDATA%\belmont-tools\settings.json. Sebagian besar bisa diubah dari panel Settings; beberapa hanya ada di berkas.

Folder kerja

Batas gerak agen. Setiap path yang diminta agen diselesaikan relatif terhadap folder ini, dan kalau hasilnya keluar dari folder tersebut, permintaannya ditolak — bukan ditanyakan, langsung ditolak.

Bawaannya Desktop. Ganti ke folder proyek yang spesifik.

Satu pengecualian penting

Batas folder kerja tidak berlaku untuk server MCP. Server MCP adalah program terpisah yang kamu sendiri daftarkan, dan Belmont Tools tidak bisa mengekang apa yang mereka sentuh. Perlakukan setiap server MCP seperti program biasa yang kamu pasang: hanya tambahkan yang kamu percayai.

Mode izin

Letaknya di dekat kotak pesan, bukan di panel Settings, karena sering diganti.

ModeTulis / sunting berkasPerintah shell
Supervised (bawaan)Minta persetujuanMinta persetujuan
Accept editsLangsung jalanMinta persetujuan
FullLangsung jalanLangsung jalan

Membaca berkas, mendaftar isi folder, mencari web, dan mengambil halaman tidak pernah meminta persetujuan di mode mana pun — semuanya hanya membaca.

Tingkat usaha

Hanya berlaku untuk Claude Code. Lima tingkat: low, medium (bawaan), high, xhigh, max.

Makin tinggi, makin lama agen berpikir sebelum bertindak — dan makin besar biayanya. medium cukup untuk hampir semua hal; naikkan untuk masalah yang butuh penalaran berlapis, turunkan untuk tugas mekanis.

System prompt

Instruksi yang selalu ikut di setiap percakapan. Bawaannya tiga kalimat dalam bahasa Inggris. Di sinilah tempatnya menulis hal seperti “selalu jawab dalam bahasa Indonesia”, konvensi kode proyekmu, atau larangan tertentu.

Tampilan

Sembilan tema. Hanya satu yang terang:

catppuccin (bawaan) · tokyo-night · rose-pine · nord · gruvbox · dracula · one-dark · obsidian · terang

Bahasa antarmuka tersedia dalam Bahasa Indonesia dan English, bawaannya English.

Pencarian web

Tanpa kunci apa pun, pencarian web memakai DuckDuckGo. Kalau kamu mengisi kunci Tavily, pencarian beralih ke Tavily yang hasilnya lebih rapi dan dirancang untuk dibaca model. Tavily punya kuota gratis bulanan.

Konteks ringkas

Opsi lean context memperkecil jumlah informasi yang dikirim ke model setiap giliran. Menghemat biaya dan memperlambat penuhnya konteks, dengan imbalan agen mengingat lebih sedikit detail. Bawaannya mati.

Server MCP

Model Context Protocol adalah cara standar menambahkan tool baru ke agen. Belmont Tools menjalankan server MCP sebagai proses anak lewat stdio.

Kamu bisa menambahkannya satu per satu, atau mengimpor JSON konfigurasi yang sudah kamu punya dari aplikasi lain. Saat memakai Claude Code, tool dari MCP muncul dengan nama berpola mcp__<server>__<tool>.

Opsi yang hanya ada di berkas

Tiga opsi ini nyata dan berpengaruh, tapi belum punya kolom di panel Settings. Untuk mengubahnya: tutup aplikasi dulu, sunting %APPDATA%\belmont-tools\settings.json dengan Notepad, lalu buka kembali. Kalau aplikasi masih jalan, perubahanmu akan tertimpa saat ia menyimpan.

ambangRingkas — ambang peringkasan otomatis

Bawaannya 80, artinya saat konteks mencapai 80% penuh, percakapan diringkas otomatis supaya bisa terus berjalan. Isi 0 untuk mematikannya.

Ini yang mencegah percakapan panjang berhenti mendadak di tengah jalan pada penyedia API. Turunkan ke 70 kalau kamu masih kena mentok; naikkan ke 90 kalau kamu lebih mementingkan ingatan utuh daripada kelancaran.

Satu syarat

Peringkasan otomatis hanya aktif kalau ukuran jendela konteks model itu diketahui aplikasi. Untuk model yang sangat baru atau endpoint custom, ukurannya kadang tidak diketahui — dan dalam kasus itu peringkasan tidak dijalankan sama sekali, karena menebak ambang akan lebih berbahaya daripada tidak bertindak.

Claude Code tidak memakai opsi ini; ia punya mekanisme /compact sendiri. Tombol Compact di antarmuka bekerja untuk keduanya, kapan saja.

maxSteps — batas langkah per giliran

Bawaannya 40. Berapa kali agen boleh memanggil tool dalam satu giliran sebelum dipaksa berhenti. Ini jaring pengaman terhadap agen yang berputar-putar tanpa kemajuan.

Naikkan kalau tugasmu memang panjang dan sering terpotong di tengah; turunkan kalau kamu ingin dipanggil lebih sering untuk mengarahkan.

windowBounds — posisi jendela

Internal, diisi sendiri oleh aplikasi untuk mengingat ukuran dan posisi jendela. Tidak perlu disentuh. Kalau jendelanya pernah terbuka di luar layar, hapus nilai ini agar kembali ke posisi awal.

Cadangkan sebelum menyunting

settings.json harus tetap JSON yang sah. Satu koma yang salah bisa membuat pengaturanmu gagal dibaca. Salin dulu berkasnya ke tempat lain sebelum mengubah apa pun.
